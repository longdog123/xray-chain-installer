# 错误提示可定位与发布计划

用户已授权整体排查、优化和自行发布。成功提示保持现有简短输出；错误应说明对象、失败步骤、已采取的动作及下一步。真实上游故障已确认，本次不继续诊断该上游、不使用客户 IP 作为测试夹具。

## 实现边界

- SOCKS5 新增失败显示本批序号、总数和经过格式校验的网关地址/端口；编辑失败显示对应节点编号。每个检测站显示固定站点名、curl 分类和针对性建议。不显示账号、密码、完整输入、节点链接或原始错误。
- 状态页按节点保留安全诊断，区分网关、直连、入口监听、服务和配置失败；正常与暂停输出保持简短。并发结果必须互相隔离。
- 系统依赖、Xray 下载、BBR、端口选择、安装文件、升级检查、配置验证和部署错误逐项检查。补充缺失的对象/步骤/操作指引，已有清楚的提示保留。
- 原始日志只提取预定义原因类别，未知原文不直接回显。回滚的文件恢复和服务恢复结果必须如实报告，不能在恢复失败时声称已恢复。保持所有原有恢复动作与失败停止机制。
- 不增加成功日志，不改变节点状态、端口、凭据、出口、运行配置及升级不变量。自动更新仍强制执行，失败仍停止。

## 工作与验证

1. 分别检查 SOCKS/输入、状态页和系统/升级/部署错误，保存覆盖范围。
2. 用隔离夹具复现批量第 11 条失败无法识别、状态失败缺少目标和原因、原始日志泄漏及回滚结果不实。
3. 分范围修改提示和诊断传递，检查成功输出、默认拒绝、整批取消和无凭据泄漏。
4. 运行既有兼容性套件及新增错误场景，复用已验证的 Xray 运行时，记录最终源码哈希、时间、结果、清理及排除范围。
5. 运行发布前检查并复核补丁；只使用 longdog123，经本机代理发布。验证主分支、现用及旧安装地址下载字节一致，保存脱敏发布记录。
