# 域名入口与云端验收

用户确认一台 VPS 共用一个入口域名。采用现有 REALITY，入口域名与 REALITY SNI 分开，不申请证书、不改变协议。

- 菜单新增第 12 项，保留原编号；`puppyip address <域名|IPv4|auto>` 设置全局入口。无参数交互输入，回车保留。用户后续补充：首次交互安装必须询问入口域名，回车使用自动 IP，输入域名则统一使用它；后续新增不重复询问。初装明确预设 `XRAY_CHAIN_ADDRESS` 时优先使用预设，无终端自动化保留自动 IP 默认。
- 只修改状态中的 `serverAddress`。不迁移 schema，不修改时间戳、未知字段或任何节点属性。备份原状态、原子替换，并检查除该字段外完全一致；无需停止或重启服务。
- 域名规范化为小写并接受一个末尾点；拒绝 URL、端口、通配符、无点名称和含认证信息的输入，不回显无效原文。不强制当前 DNS 已生效，允许先设置再等待传播；成功仅表示入口保存。
- `auto` 只在唯一可用本机公网 IPv4 与公网探测一致时恢复 IP 模式；歧义或探测失败保留原入口。原有固定地址设置和查看时刷新规则保留。
- 链接生成和升级保护已有域名支持，沿用原路径；首次客户端需改为域名一次，后续同机换 IP 只更新 A 记录。Cloudflare 使用仅 DNS。更换整台 VPS 必须保留原配置和凭据；域名不保证不可达 IP 恢复，也不保证 DNS 即时刷新。

验收使用 GitHub 托管 Ubuntu，现仓库无 CI，补齐全部既有套件和新入口测试，保留源码、工作流、run、运行时、测试文件及结果哈希。禁止重建已退役 WSL；本地仅编辑、语法及窄诊断。测试分支推送用于 CI，不等于发布 main。
