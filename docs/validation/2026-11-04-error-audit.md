# 0.2.23 错误提示排查范围

本次按用户授权检查错误提示，保持成功输出简短。旧版为 `7767e5f`（0.2.22）。真实上游故障由用户另行联系上游，本次测试不访问该上游或任何客户服务器。

| 范围 | 排查结论及处理 |
| --- | --- |
| 批量新增、单条新增、修改出口 | 原提示缺目标；增加序号/节点编号、经校验的网关地址端口、固定检测站、错误分类和建议。确认提示区分继续单条验证与整批部署，默认拒绝保持不变。 |
| 输入与选择 | 格式错误显示批次位置和可安全识别的地址；不回显原始条目。拒绝非法 IPv4 和超长端口，不再以可能溢出的 Bash 算术解析节点编号。 |
| 状态检测 | 各节点独立诊断，区分实际出口、配置字段、服务状态、入口未监听和检测站失败；正常/暂停/出口变化的现有输出保持。 |
| 依赖、下载与更新 | 区分 apt 索引/安装阶段、GitHub API/脚本下载/响应及脚本校验、Xray 发布查询/下载/摘要/解压；失败仍停止，未放宽更新校验。 |
| 锁、临时目录、运行账户与文件部署 | 增加目标目录/文件、写入或替换阶段及权限/空间建议。备份创建失败不得继续部署。 |
| REALITY 与 BBR | 目标检测准确描述 TCP/TLS 检查，显示目标/SNI。BBR 区分配置来源、内核能力、读取/写入/应用/恢复阶段，不再笼统建议重启即可恢复。 |
| Xray 配置与服务日志 | 自动显示仅提取固定原因类别；任意原始行、未知错误内容、凭据和链接不直接回显。显式 `puppyip logs` 的用途及行为未改。 |
| 部署与回滚 | 保留全部原恢复步骤；记录具体文件与 systemd 操作失败，核对原本活动服务是否恢复运行。只有全部恢复操作成功才声明已恢复，其他情况保留备份路径并提示人工检查。 |
| 升级兼容性 | 保留节点身份、运行配置、凭据及 REALITY 不变量检查。已有清晰保护提示保留，未输出敏感差异值。 |
| 平台、卸载与正常提示 | 已有适用系统、破坏性操作确认及备份保留说明足够具体，保留。正常连接结果、成功状态和进度不增加逐条日志。 |

验证证据见同目录 `2026-11-04-socks-error-context.json`、`2026-11-04-status-diagnostics.json`、`2026-11-04-system-errors-red.json` 与最终 `2026-11-04-error-diagnostics-regressions.json`。单项测试对应各自源码快照，最终组合回归记录发布源码哈希。网络、系统服务和用户配置均使用隔离夹具；这不代表已验证所有客户网络。
